+## 🔄 MLOps, Pipeline Orchestration & Monitoring (Block C)
+
+A production-grade ML system requires end-to-end reproducibility, continuous performance tracking, automated data quality validation, and early detection of distribution shift.
+
+### 1. Reproducible Pipeline DAG with DVC (`dvc.yaml`)
+
+The entire data and modeling lifecycle is managed through a Directed Acyclic Graph (DAG) defined in [`dvc.yaml`](dvc.yaml). Each stage specifies exact inputs, code dependencies, and output artifacts:
+
+```text
+      +------------+          
+      | build_grid |          
+      +------------+          
+              *               
+      +--------------+        
+      | process_data |        
+      +--------------+        
+              *               
+    +----------------+        
+    | build_features |        
+    +----------------+        
+         *        *           
+       **          **         
+      *              *        
++-------+         +-------+   
+| drift |         | train |   
++-------+         +-------+   
+                      *       
+                 +---------+  
+                 | explain |  
+                 +---------+  
+```
+
+To reproduce or inspect the pipeline:
+```bash
+# Verify the stage dependency graph
+dvc dag
+
+# Reproduce the entire DAG (or only stale stages)
+dvc repro
+```
+
+### 2. Experiment Tracking with MLflow
+
+All model runs, Bayesian search parameters, multi-horizon metrics, and visualization artifacts are automatically tracked in a centralized MLflow database (`sqlite:///mlflow.db`):
+
+- **Logged Parameters**: Best Optuna hyperparameter set (`n_estimators`, `learning_rate`, `num_leaves`, `reg_alpha`, etc.), spatial validation strategy, seed, and dataset sizes.
+- **Logged Metrics**: Multi-horizon evaluations (1d, 3d, 7d), PR-AUC, ROC-AUC, Brier score, and Recall@P50 for both raw and Platt-calibrated models, plus baseline benchmarks (Persistence, Climatology, Logistic Regression).
+- **Logged Artifacts**: Serialized model metadata (`training_metadata.json`), comparative CSV reports, and high-resolution evaluation figures.
+
+To launch the MLflow dashboard locally:
+```bash
+mlflow ui --backend-store-uri sqlite:///mlflow.db
+# Opens at http://localhost:5000
+```
+
+### 3. Data & Concept Drift Monitoring (`src/monitoring/drift_detector.py`)
+
+Environmental and climatological regimes shift over time (e.g., severe droughts and heatwaves during El Niño events). To prevent silent model degradation in production, the system computes:
+
+1. **Population Stability Index (PSI)**:
+   - $\text{PSI} < 0.10$: Stable distribution (No action needed).
+   - $0.10 \le \text{PSI} < 0.25$: Moderate drift (Warning alert, flag for monitoring).
+   - $\text{PSI} \ge 0.25$: Critical drift (Action required, automated retraining trigger).
+2. **Two-Sample Kolmogorov-Smirnov (KS) Test**: Non-parametric test assessing whether baseline and operational samples originate from identical continuous distributions.
+
+#### Real Drift Benchmark Results (Baseline 2016–2023 vs Operational 2024–2025):
+- **Monitored Features**: 11 core climatological and biophysical variables.
+- **Stable Features (9/11)**: `PRECTOTCORR` ($\text{PSI} = 0.0094$), `WS10M` ($\text{PSI} = 0.0084$), `fire_count_7d` ($\text{PSI} = 0.0526$), `neighbor_fire_7d` ($\text{PSI} = 0.0381$), `dtr` ($\text{PSI} = 0.0560$), etc.
+- **Moderate Drift Detected (2/11)**:
+  - `T2M_MAX` ($\text{PSI} = 0.1503$, $p < 0.001$): Mean maximum temperature surged from **32.0°C** in 2016–2023 to **33.4°C** in 2024–2025, accurately capturing the historic 2024 central Brazil heatwave.
+  - `vpd` ($\text{PSI} = 0.1067$, $p < 0.001$): Mean Vapor Pressure Deficit increased from **1.17 kPa** to **1.46 kPa**, indicating significantly drier atmospheric fuel drying conditions.
+  - `dry_days`: Mean consecutive rainless days increased from **10.0 days** to **13.0 days**.
+- **Critical Drift (0/11)**: No feature crossed the $\text{PSI} \ge 0.25$ threshold.
+
+The drift analysis automatically generates [`reports/drift_report.json`](reports/drift_report.json) and visual summary plots in [`reports/figures/drift_summary.png`](reports/figures/drift_summary.png). It is also exposed live via the API endpoint:
+```bash
+curl http://localhost:8000/drift
+```

+- **Production Container** ([`Dockerfile`](Dockerfile)): Based on `python:3.12-slim`, includes system OpenMP runtime (`libgomp1`) required for LightGBM, `curl` for container health monitoring, exposes ports 8000 (FastAPI) and 8501 (Streamlit), and includes an automated `HEALTHCHECK` pinging `http://localhost:8000/health`.

+### 3. Monitoramento de Data Drift e Desvio de Conceito (`src/monitoring/drift_detector.py`)
+
+Regimes climáticos e ambientais variam expressivamente ao longo dos anos (como secas históricas e ondas de calor associadas a eventos intensos de El Niño). Para evitar degradação silenciosa em produção, o sistema calcula:
+
+1. **Population Stability Index (PSI)**:
+   - $\text{PSI} < 0.10$: Distribuição estável (Nenhuma ação requerida).
+   - $0.10 \le \text{PSI} < 0.25$: Desvio moderado (Alerta de aviso, manter sob vigilância).
+   - $\text{PSI} \ge 0.25$: Desvio crítico (Ação necessária, acionar pipeline de retreino).
+2. **Teste Kolmogorov-Smirnov (KS) Bicaudal**: Teste não-paramétrico contínuo avaliando se a base histórica de treino e os dados operacionais recentes pertencem à mesma distribuição subjacente.
+
+#### Resultados Reais de Drift (Base Histórica 2016–2023 vs Operação 2024–2025):
+- **Features Monitoradas**: 11 variáveis climáticas e biofísicas centrais.
+- **Variáveis Estáveis (9/11)**: `PRECTOTCORR` ($\text{PSI} = 0.0094$), `WS10M` ($\text{PSI} = 0.0084$), `fire_count_7d` ($\text{PSI} = 0.0526$), `neighbor_fire_7d` ($\text{PSI} = 0.0381$), `dtr` ($\text{PSI} = 0.0560$), etc.
+- **Desvio Moderado Detectado (2/11)**:
+  - `T2M_MAX` ($\text{PSI} = 0.1503$, $p < 0.001$): A temperatura máxima média saltou de **32.0°C** no período base para **33.4°C** em 2024–2025, capturando com exatidão a onda extrema de calor no Centro-Oeste durante o El Niño de 2024.
+  - `vpd` ($\text{PSI} = 0.1067$, $p < 0.001$): O Déficit de Pressão de Vapor médio subiu de **1.17 kPa** para **1.46 kPa**, refletindo condições atmosféricas significativamente mais secas e propensas à propagação de fogo.
+  - `dry_days`: A média de dias consecutivos sem chuva aumentou de **10.0 dias** para **13.0 dias**.
+- **Desvio Crítico (0/11)**: Nenhuma variável ultrapassou o limiar de $\text{PSI} \ge 0.25$.
+
+O módulo exporta automaticamente [`reports/drift_report.json`](reports/drift_report.json) e o gráfico [`reports/figures/drift_summary.png`](reports/figures/drift_summary.png), disponibilizando os dados em tempo real no endpoint da API:

+curl http://localhost:8000/drift
+```

+"""Data and Concept Drift Detection for Brazil Wildfire Risk Forecast.
+
+Monitors distribution drift between baseline training periods (2016–2023)
+and operational/testing periods (2024–2025 or real-time incoming data).
+
+Key Metrics:
+- Population Stability Index (PSI):
+    * PSI < 0.10: No significant drift (Stable)
+    * 0.10 <= PSI < 0.25: Moderate drift (Warning, continue monitoring)
+    * PSI >= 0.25: Critical drift (Action required, trigger retraining)
+- Kolmogorov-Smirnov (KS) 2-sample test:
+    * Non-parametric test for continuous distribution shift (p-value and statistic).
+"""

+def calculate_psi(baseline: np.ndarray, current: np.ndarray, num_bins: int = 10) -> float:
+    """Calculate Population Stability Index (PSI) between two 1D distributions.
+
+    Args:
+        baseline: Baseline / reference distribution array
+        current: Current / operational distribution array
+        num_bins: Number of quantile bins to segment
+
+    Returns:
+        PSI float value
+    """
+    b = baseline[~np.isnan(baseline)]
+    c = current[~np.isnan(current)]
+
+    if len(b) == 0 or len(c) == 0:
+        return 0.0
+
+    # Quantile bins based on baseline
+    quantiles = np.linspace(0, 100, num_bins + 1)
+    bins = np.percentile(b, quantiles)
+    bins[0] = -np.inf
+    bins[-1] = np.inf
+    bins = np.unique(bins)
+    if len(bins) < 2:
+        return 0.0
+
+    b_counts, _ = np.histogram(b, bins=bins)
+    c_counts, _ = np.histogram(c, bins=bins)
+
+    b_pct = b_counts / len(b)
+    c_pct = c_counts / len(c)
+
+    # Laplace smoothing to prevent division by zero
+    eps = 1e-4
+    b_pct = np.clip(b_pct, eps, None)
+    c_pct = np.clip(c_pct, eps, None)
+
+    b_pct = b_pct / np.sum(b_pct)
+    c_pct = c_pct / np.sum(c_pct)
+
+    psi_val = np.sum((c_pct - b_pct) * np.log(c_pct / b_pct))
+    return float(psi_val)
